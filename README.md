# Gestão Logística e Entregas

Projeto em desenvolvimento para gerenciar usuários, produtos, pedidos, veículos e entregas.

## Tecnologias
Java, Spring Boot, Spring Data JPA, PostgreSQL, Maven e Lombok.

## Organização
O código está dividido em entidades, controllers, services, repositories e DTOs.

## Objetivo
Praticar o desenvolvimento de uma API REST com Java e Spring Boot, utilizando banco de dados relacional e organização em camadas.
